# sh_common — общие скрипты

Работают и в prod, и в dev.

| Скрипт | Что делает |
|--------|-----------|
| install-tinyrdm.sh | Установка Tiny RDM |
| log_show.sh | Показ логов |
| sbp_mq_service_start.sh | Запуск сервиса |
| **backup_sbp_mq.sh** | **Бэкап проекта SBP MQ (DEV/PROD) → /sbp/backups** |
| **check_backup.sh** | **Проверка содержимого бэкапа** |
